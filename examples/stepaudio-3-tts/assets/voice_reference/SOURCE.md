# 个性化音色参考录音来源

本目录保存公开网络参考音频的原文件，供复刻和原声对照。来源为 [LJ Speech 数据集发布页](https://keithito.com/LJ-Speech-Dataset/)，录音者为 Linda Johnson（LibriVox），数据整理者为 Keith Ito。发布者将文本、音频与标注列为 public domain。

- 原文件：[LJ025-0076.wav](LJ025-0076.wav)
- 原始下载地址：[发布者提供的 WAV](https://keithito.com/LJ-Speech-Dataset/LJ025-0076.wav)
- 对应文字：[transcript.txt](transcript.txt)
- 新合成文本：[new_text.txt](new_text.txt)
- 来源、格式和 SHA-256：[source.json](source.json)

原音频约 8.397 秒，22050 Hz、单声道、16 位 PCM。下载后未裁剪、未重采样；复刻上传的就是此文件。它是公开数据集中的真人朗读素材，不是 StepFun 预置音色的合成音频。本例采用英文原音与英文新文本，正文使用中文解释流程。

听辨时先播放原音，再播放同一音色合成的新文本；新文本与原录音内容不同，用于观察声音特征是否延续。合成文件应标为 AI 生成，不能当作录音者实际说过的话。
